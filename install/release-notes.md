# Версия 2.2.0

## Новые возможности

* [#1725](https://github.com/EvilBeaver/OneScript/pull/1725) Добавлена глобальная функция `ТекущийПоток()`, возвращающая объект `ПотокИсполнения`.
* Добавлен CLI-флаг `-c` для выполнения кода BSL из строки командной строки.
* [#1532](https://github.com/EvilBeaver/OneScript/issues/1532). В `ЗаписьJSON` добавлен метод `ОткрытьПоток()`, чтобы объект мог писать в потоки. Также у `ЗаписьJSON` появилось свойство `Параметры`. Улучшена совместимость API с платформой 1С:Предприятие.
* [#1711](https://github.com/EvilBeaver/OneScript/pull/1711) Добавлена глобальная функция `ЗаписатьДатуJSON` / `WriteJSONDate` и перечисление `ВариантЗаписиДатыJSON` для сериализации даты в JSON в форматах, совместимых с 1С.
* В `СписокЗначений` добавлены свойства `ТипЗначения` и `ДоступныеЗначения`, у `ЭлементСпискаЗначений` добавлен метод `ПолучитьИдентификатор`.
* `СписокЗначений.ЗагрузитьЗначения` приводит значения с учётом `ТипЗначения`; исправлены сортировка по значению с учётом типов, поиск по `ДоступныеЗначения`, преобразование в строку и проверки индекса.

## Исправление ошибок

* [#1359](https://github.com/EvilBeaver/OneScript/issues/1359). Значительно улучшена совместимость Native API с 1С: Поддержаны выходные параметры методов, исправлена ошибка регистрации типов, реализован обмен значениями типа `Дата`, исправлен жизненный цикл библиотек и устойчивость колбэков к сборке мусора.
* [#1718](https://github.com/EvilBeaver/OneScript/issues/1718) Исправлена потокобезопасность `ФоновыеЗадания`: одновременный запуск и опрос списка больше не приводят к `InvalidOperationException`, `ПолучитьТекущее()` ищет задание за O(1).
* `ФоновыеЗадания.ОжидатьЗавершенияЗадач()` больше не удаляет из реестра задания, запущенные во время ожидания.
* [#1656](https://github.com/EvilBeaver/OneScript/issues/1656) Приведена точность типа `Дата` и сериализация дат в JSON к поведению 1С.
* Исправлено округление долей секунды при сложении/вычитании даты с числом (граничные значения вроде `0.00015`).
* [#1696](https://github.com/EvilBeaver/OneScript/issues/1696) Запрещено чередование директив `#native` и `#stack` в одном модуле: режим компиляции фиксируется первой аннотацией.
* [#1705](https://github.com/EvilBeaver/OneScript/issues/1705) Исправлена `ЗаписьXML.Закрыть()`: нет падения без установленного приёмника, метод возвращает строку.
* [#1707](https://github.com/EvilBeaver/OneScript/issues/1707) Исправлена совместимость и обработка ошибок `ЗаписьXML.ЗаписатьТипДокумента`.
* Исправлено экранирование символов при записи JSON.
