# Бенчмарки OneScript

Микробенчмарки на [BenchmarkDotNet](https://benchmarkdotnet.org/).

- `BslCallBenchmarks` — вызовы из 1Script через стековую машину: методы контекста, функции скрипта, `Рефлектор`, блокировки. Каждый бенчмарк — цикл на 10 000 итераций, время и память показаны на одну итерацию. Цена самого вызова — разница с `EmptyLoop`.
- `ContextCallBenchmarks` — вызов метода контекста из C# без машины: обертка метода и преобразование значений (`ContextValuesMarshaller`).

## Запуск

Только в Release:

```
dotnet run -c Release --project src/Tests/OneScript.Benchmarks -- --filter "*"
```

Остальные аргументы — обычные аргументы BenchmarkDotNet (`--filter "*BslCall*"`, `--list flat`, `--job short` и т.д.).

## Сравнение версий движка

Опция `--engine имя=путь/к/src` добавляет еще одну версию движка — например, `git worktree` другой ветки. Базовой считается версия из этого репозитория, в таблице будет колонка `Ratio` относительно нее. Опцию можно повторять:

```
git worktree add ../os-develop develop
dotnet run -c Release --project src/Tests/OneScript.Benchmarks -- --filter "*" --engine develop=../os-develop/src
```

BenchmarkDotNet пересобирает бенчмарки против каждой версии и запускает каждую в отдельном процессе. Каждая версия запускается трижды: JIT от процесса к процессу может скомпилировать горячий путь по-разному, и разница в одном запуске бывает случайной. Версии для одного бенчмарка идут подряд, а их порядок чередуется от бенчмарка к бенчмарку — иначе нагрев процессора и фоновая нагрузка за время прогона сдвигали бы `Ratio` в одну сторону. Сравнивать можно версии, у которых совпадает публичный API, который используют бенчмарки.
